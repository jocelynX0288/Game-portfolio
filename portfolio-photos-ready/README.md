# Portfolio - drag-and-drop media

1. Put your MP4 files inside `assets/`.
2. Rename them exactly as listed below.
3. Double-click `index.html` to preview. No HTML edits necessary.

NightShift:
- `find-termites.mp4`
- `rearrange-furniture.mp4`
- `close-the-door.mp4`

Lightbound:
- `light-candle.mp4`
- `free-dad.mp4`
- `spider-attack.mp4`

Optional Lightbound torch image: `torch-prop.png`.

All six videos are configured to autoplay, be muted, loop, and play inline. MP4 H.264 encoding is recommended. The empty player will appear dark until you put the matching file in assets.


PHOTOS: put your About portrait at assets/about-photo.jpg (JPG). Put your torch picture at assets/torch-prop.png (PNG). No HTML edits needed. The lower duplicate Torch Prop caption is removed.
